# PSiron2.1
Evidence-driven security assessment orchestration platform.

Flow: ingest -> scope -> discover -> profile -> plan -> scan -> analyze -> correlate -> verify -> evidence -> attack graph -> risk factors -> remediation -> regression -> coverage -> report.

Runtime has no AI or LLM dependency. Active testing requires explicit authorization, exact scope, rate/concurrency/time/resource limits and audit logging. Confirmed findings require evidence. Not tested is never represented as secure.

See docs/PRD.md, docs/TRD.md and docs/ARCHITECTURE.md.
